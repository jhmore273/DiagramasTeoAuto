Cómo usar el diseñador
  • Crea estados con doble clic. Doble clic sobre un estado lo marca como estado de aceptación.
  • Mantén Shift y arrastra entre estados para crear una transición. Desde un espacio vacío hacia un estado crea la flecha inicial; vuelve al mismo estado para un bucle.
  • Arrastra estados y transiciones para moverlos. Selecciona un elemento y escribe su etiqueta; usa Retroceso para corregir. Cuando la etiqueta esté vacía, otra pulsación de Retroceso elimina el estado o la flecha seleccionada. Al borrar un estado también se eliminan sus transiciones. Supr elimina directamente el elemento seleccionado.
  • Escribe S_0 para un subíndice. Usa /lambda → λ, /epsilon → ε, /beta → β o /Delta → Δ para letras griegas. También funcionan los atajos con barra invertida, como \lambda.
  • Amplía el lienzo a por lo menos 2400 × 1600. Usa las barras de desplazamiento para recorrerlo. La vista se adapta a la ventana; el diagrama conserva sus coordenadas.
  • Tamaño normal restaura la vista de 800 × 600. Las zonas adicionales siguen disponibles mediante desplazamiento. Esc sale de pantalla completa.
  • Usa ← y → para mover el cursor dentro de las etiquetas, ↑ y ↓ para cambiar de línea e Inicio/Fin para ir al comienzo o final. Las letras griegas y los subíndices se recorren como un solo símbolo. Escribir o usar Retroceso modifica el texto en esa posición.
  • Selecciona una flecha y pulsa Alt + L o Cambiar lado del texto para alternar su etiqueta de lado: arriba/abajo en flechas horizontales e izquierda/derecha en las verticales. En el navegador, Ctrl + L abre la barra de direcciones. Enter crea una nueva línea en la etiqueta.
  • Ctrl + Z o Deshacer revierte la última edición, incluido Borrar todo. Cada lienzo tiene su propio historial durante la sesión.
  • El panel muestra carpetas y lienzos en forma de árbol. Pulsa una carpeta para expandirla o contraerla. Arrastra un lienzo o una subcarpeta sobre otra carpeta para moverlo. Para sacarlo a la carpeta principal, suéltalo en Inicio · suelta aquí. El contenido aparece indentado a la derecha.
  • Exportar todo JSON guarda todos los lienzos y carpetas en un respaldo editable. Importar JSON añade ese respaldo conservando los lienzos existentes. + Carpeta crea carpetas o subcarpetas; Mover lienzo organiza el diagrama activo en la carpeta elegida.
  • + Nuevo crea otro diagrama. El panel lateral muestra tus lienzos guardados; pulsa un nombre para abrirlo, el lápiz para renombrarlo o × para borrarlo con confirmación. Todos se guardan automáticamente en este equipo.
  • Los lienzos se guardan en este navegador y equipo. No se comparten entre personas ni se sincronizan con la aplicación de escritorio. Al borrar los datos del sitio se eliminan sus lienzos guardados. PNG, SVG y LaTeX descargan archivos con el nombre del lienzo, por ejemplo Diagrama_Tarea8_Problema1.png, .svg o .tex. SVG y LaTeX también muestran el texto para copiarlo.
